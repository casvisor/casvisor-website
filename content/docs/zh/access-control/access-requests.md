不必为每件临时的活都让管理员写一条[权限](./permissions.md)，用户可以自己申请。一条**访问申请**写明资产、账号、动作、时间和理由。管理员批准后，Casvisor为这个用户单独加一条权限，到了结束时间就和其他权限一样不再生效。

页面是**访问申请**（`/access-requests`），每个人的菜单里都有。用户在这里看到自己的申请，管理员看到本组织所有的申请。

## 提交申请

在这个页面点**申请访问**（不是管理员的用户在**资产**页面的工具栏里也有这个按钮），填写：

| 字段 | 含义 |
| --- | --- |
| 资产 | 本组织的一个或多个资产。可以从所有资产里选，不限于已经能连的；列表里有名称、显示名称、协议和标签，没有地址，也没有账号的密码。 |
| 账号 | 要以哪些[账号](../assets/accounts.md)连接，从所选资产的用户名里选。不填表示每个资产自己的账号。不能申请`*`。 |
| 动作 | Connect（总是包含），以及Copy、Paste、Upload、Download、Forward中的任意几个。见[动作](./permissions.md#动作)。 |
| 开始时间、结束时间 | 从什么时候开始，不填就是现在；到什么时候结束。结束时间必填，而且要晚于现在。 |
| 申请理由 | 为什么需要。必填。 |

点**提交申请**后，申请处于*待审批*。Casvisor不会发通知，管理员在这个页面里看到。申请还在待审批时，提交它的用户可以**取消**，申请变成*已撤回*。

## 审批

管理员对申请有三种操作：

- **批准**，针对待审批的申请。对话框里显示申请内容，管理员可以去掉部分动作（Connect保留）、把结束时间提前、填写审批意见。批准只能缩小申请的范围，加动作或推迟结束时间会被拒绝。批准后会新增一条名为`request_<编号>`的权限：用户只有申请人，资产和账号是申请的那些，动作是批准的那些，开始和结束时间照申请，不限来源IP；描述里写着审批人和申请理由。申请变成*已批准*，从开始时间起，这些资产出现在用户的工作台里。
- **驳回**，针对待审批的申请，可以填审批意见。申请变成*已驳回*，什么都不授予。
- **收回**，针对已批准的申请，可以填审批意见。删除这个申请生成的权限，申请变成*已收回*，它放行的会话立刻断开，见[权限收回即断开](../audit/sessions.md#权限收回即断开)。

列表里每条申请显示申请人、状态、资产、账号、动作、结束时间和理由；审批过的还显示审批人（`组织/用户名`）、审批意见和生成的权限的链接。

申请生成的权限是一条普通权限：在**授权**里能看到，可以修改或关掉，到了结束时间不用谁收回就会失效。在列表里删除申请不会删除它生成的权限；要收回访问，就收回申请或者删除那条权限。

## 日志

提交、撤回、批准、驳回和收回申请都是接口调用，会记进[操作日志](../audit/operation-logs.md)，动作分别是`add-access-request`、`cancel-access-request`、`approve-access-request`、`reject-access-request`和`revoke-access-request`。按批准的申请打开的会话，和其他会话一样会被列出、录像，并按[命令规则](../audit/commands.md)检查。
