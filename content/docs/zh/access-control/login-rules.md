登录规则决定用户登录时怎么处理，在用户接触任何资产之前。每条规则覆盖一部分用户、来源IP和时间，并规定动作：放行、拒绝、暂停到管理员批准，或者要求输入验证器App里的验证码。它和[权限](./permissions.md)互补，权限决定登录后的用户能连哪些资产。

管理员在**登录规则**页面管理规则，在**登录复核**页面批准被暂停的登录。

## 一条规则

| 字段 | 含义 |
| --- | --- |
| 优先级 | 按优先级从小到大逐条匹配，第一条匹配的规则生效。没有匹配的规则时允许登录。 |
| 用户、用户组 | 规则覆盖谁。`*`表示所有人，两项都留空也表示所有人。 |
| 来源IP | IP或网段，例如`10.0.0.0/8`。留空表示所有地址。地址的取法和[权限](./permissions.md#客户端ip)相同。 |
| 星期 | 规则生效的星期。留空表示每天。 |
| 时间段 | 开始和结束，例如`09:00`到`18:00`。留空表示全天。结束早于开始（例如`22:00`到`06:00`）表示跨午夜，算在开始的那一天。 |
| 时区 | IANA时区，例如`Asia/Shanghai`。留空用服务器的时区。 |
| 登录方式 | **网页**是登录Casvisor网站，**SSH网关**是经[SSH网关](../assets/ssh-gateway.md)的`ssh`、`scp`、SFTP和[本地客户端](../assets/local-clients.md)，**数据库客户端**是用数据库令牌登录[数据库代理](../assets/local-clients.md#数据库客户端)的客户端。留空表示三种都算。 |
| 动作 | **放行**、**拒绝**、**复核**或**要求两步验证**，见下文。 |
| 复核人 | 动作是复核时，可以批准的管理员。留空表示本组织的所有管理员。 |
| 启用 | 没启用的规则会被跳过。 |

一个组织的规则对这个组织的用户生效。Casdoor的`built-in`组织的用户不受任何规则约束。

## 动作

- **放行**：允许登录。用来在更宽的规则前面做例外：优先级10的规则对办公网放行，再加一条优先级20、对所有人拒绝的规则，就只能从办公网登录。
- **拒绝**：拒绝登录。网页登录页会提示是哪条规则拒绝的，`ssh`里也会显示。
- **复核**：暂停登录，等管理员批准或拒绝，最多等10分钟。网页上登录页显示正在等待，批准后自动完成登录。经SSH网关时，`ssh`显示请求编号并等待。复核人写的备注会显示给用户。
- **要求两步验证**：要求输入验证器App里的验证码。网页上它作用于[内置账号](./users-and-admins.md#两步验证)：还没开启两步验证的用户可以登录，但会被带到**我的账号**，开启之前什么都做不了。使用Casdoor登录时，两步验证在Casdoor里设置，这条规则对网页登录直接放行。经SSH网关时，`ssh`在公钥之后要求输入验证码；还没开启两步验证的用户和所有Casdoor用户会被拒绝。对所有人设一条这样的规则，就是强制开启两步验证。

只通过`*`或用户组覆盖到的组织管理员，不会被拒绝或暂停复核，防止一条宽泛的规则把所有管理员锁在外面。在**用户**里点名了这个管理员的规则才对他生效。

## 什么时候检查

网页登录时，在口令通过之后检查；用户开启了两步验证的，在验证码通过之后检查。Casvisor自己的账号和Casdoor登录都一样。经SSH网关时，在知道用户的公钥或证书之后检查，[本地客户端](../assets/local-clients.md)的一次性令牌也一样。经网关的拒绝、复核和两步验证走SSH的keyboard-interactive步骤，`ssh`、Xshell等客户端都会显示。[数据库客户端](../assets/local-clients.md#数据库客户端)每次连接都在知道令牌之后检查：拒绝时连接被拒并给出规则名；复核时客户端一直等到管理员处理（`psql`会显示一条提示），批准之后这个令牌从同一个客户端IP连接不再询问；要求两步验证时连接被拒，因为数据库客户端没法输入动态码，希望数据库客户端照常可用时，把这类规则的登录方式限定为网页和SSH网关。

规则只作用于新的登录。已经登录的用户不会被登出；要断开连接，应该收回[权限](./permissions.md)。

## 复核登录

**登录复核**页面列出被暂停的登录，显示用户、规则、来源IP、User-Agent和时间，可以按状态筛选：待复核、已批准、已拒绝、已登录、已过期、已撤回。复核人批准或拒绝，可以写一句备注给用户看。任何人都不能复核自己的登录。一次批准只能用于那一次登录，而且要在10分钟内完成。没人处理的待复核登录10分钟后过期，用户放弃等待的会被撤回。

新的复核和复核结果可以经Webhook发到钉钉、飞书、企业微信、Slack或任意URL，事件是`login_review.created`和`login_review.reviewed`。

## 审计日志

被拒绝的登录、暂停复核的登录、批准和拒绝，以及被要求先开启两步验证的用户，都会以`login-reject`、`login-review`、`login-review-approve`、`login-review-reject`和`login-mfa-setup`写入[操作日志](../audit/operation-logs.md)，并和其他记录一起[转发到syslog](../audit/export.md#转发到syslog)。
