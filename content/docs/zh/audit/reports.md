**审计**下面的各个列表一次看一条记录。报表把一段时间里的记录汇总起来：上周有多少次登录失败、来自哪里，谁开的会话最多，哪些命令规则被触发，上传了什么，哪些访问申请被批准，哪些账号改密失败，资产和授权有哪些变化。这正是审计员要的东西，也是等保检查要求定期查看的内容。

报表只有管理员能用，范围是本组织。打开**审计 → 报表**。

## 选择时间段

| 设置 | 含义 |
| --- | --- |
| 时间段 | 本周、上周、本月、上月、今天、昨天、最近7天、最近30天，或自定义日期（包含开始和结束那两天，最长一年）。一周从周一开始。 |
| 工作日和工作时间 | 上班时间，默认周一到周五09:00到18:00。在这之外的成功登录计为非工作时间登录。22:00到06:00这样的时间段跨过午夜。 |
| 时区 | 时间段和工作时间所用的时区，默认用浏览器的时区。 |

这些设置都在页面地址里，收藏或分享这个链接，打开时会按同样的条件重新统计。

## 统计什么

| 部分 | 统计 | 列表 |
| --- | --- | --- |
| 登录 | 登录成功、登录失败、非工作时间登录、被[登录规则](../access-control/login-rules.md)拒绝或要求复核的登录、被要求两步验证的登录 | 按用户、按来源IP的成功和失败次数；每一次失败、非工作时间和被拒绝的登录 |
| 会话 | 开始的会话数、总时长、涉及的用户和资产数 | 按用户、按资产、按协议的次数和时长；最长的10个会话 |
| 命令 | 命令和数据库语句的总数，以及被[命令规则](./commands.md)拦截、告警、要求复核的条数 | 命中最多的规则；按用户的命令数和被拦截数；每一条被拦截、告警或复核的命令 |
| 文件传输 | 文件面板、SFTP和SSH网关里的上传、下载，以及数据库查询结果的导出 | 按用户、按资产；每一次传输及其路径 |
| 访问申请和审批 | 这段时间里提交的[访问申请](../access-control/access-requests.md)、[登录复核](../access-control/login-rules.md)和[命令复核](./commands.md#复核)，按结果分：批准、拒绝、待审批、撤回、过期、撤销 | 申请人和审批人；每一条访问申请 |
| 账号 | [改密和推送口令](../assets/accounts.md)的成功和失败次数；这段时间里新发现和已处理的[风险账号](../assets/accounts.md#风险账号)，以及当前未处理和已忽略的数量 | 新增风险按类型；每一次改密和推送 |
| 资产和授权 | 当前资产数、新增和删除的资产；当前授权数、新增、修改、删除或撤销的授权 | 资产按协议；每一个新增或删除的资产；每一次授权变更及操作人 |

明细列表最多列出前200行，按用户、IP、资产或规则的列表列出前20个。

数字都来自Casvisor本来就保存的数据：登录、文件传输、改密和通过接口做的变更来自[操作日志](./operation-logs.md)，其余来自会话、命令、访问申请、复核、风险账号、资产和授权本身。所以报表能统计到这些数据保存得有多久；删掉操作日志或会话，报表里也就没有了。

需要知道的几点：

- 登录指网页登录。用内置账号时，登录失败按输入的用户名统计，不存在的用户名也算。用Casdoor时，口令错误由Casdoor拦下，Casvisor看不到；报表里的是Casvisor拒绝的登录，例如被登录规则拒绝的。经SSH网关登录算作会话，不算登录。
- 资产按创建时间算新增，所以同一时间段里新增又删除的资产只算在删除里。删除的资产和授权变更来自操作日志，包括`built-in`组织的管理员做的变更。
- 改密失败指Casvisor试过、但资产上没改成，例如账号不能运行`sudo`。
- 还没结束的会话，时长算到现在。

## 打印和PDF

**打印 / 另存为PDF**在单独的页面打开报表，不带菜单，始终是浅色，并打开浏览器的打印对话框。打印机选**另存为PDF**就能存成文件。页面上有按钮可以再次打印。

## Excel

**导出 Excel**把报表下载成Excel文件（`.xlsx`）：第一个工作表是概览，有组织、时间段、时区、工作时间和主要数字，后面每个部分一个工作表，包括数字、列表和明细。控制台是中文时文件是中文，否则是英文。数字写成数值单元格，可以直接求和、画图；文字写成文本，不会被当成公式。

每次下载都会记进操作日志，动作是`export-report`。

## 定时报表

**定时报表**保存按计划发邮件的报表，Excel文件作为邮件附件，例如每周一08:00发上周的报表，每月1日发上月的报表。

| 字段 | 含义 |
| --- | --- |
| 时间段 | 从生成时往回算的时间段：每周一发的选上周，每月1日发的选上月。没有自定义日期，因为每次发送都重新生成。 |
| 内容 | 包含哪些部分，每部分是Excel的一个工作表；不选就是全部。 |
| 语言 | Excel文件和邮件的语言，英文或中文。 |
| 工作日、工作时间 | 和报表页面一样。 |
| 发送到 | [邮件类型的Webhook](./notifications.md#邮件)，各自带SMTP服务器和收件人。 |
| 执行时间 | crontab写法，例如`0 8 * * 1`表示每周一08:00，按所选时区。留空只能手动发送。 |
| 时区 | 执行时间、时间段和工作时间所用的时区；留空用服务器的时区。 |

邮件正文里有主要数字，附件名是`casvisor-report-<组织>-<开始日期>-<结束日期>.xlsx`。**立即发送**马上发一次，**下载**拿到同样的Excel文件但不发送。列表里能看到下次运行的时间，以及上次运行的时间、结果和信息。发送失败时报表会记下原因，并发出`report.failed`[Webhook事件](./notifications.md)，例如发到聊天群里。

## 接口

- `GET /api/get-report-data`统计一份报表，以JSON返回。参数有`owner`和`period`，自定义日期时加`startDate`、`endDate`（例如`2026-11-01`），可选`timeZone`、`weekdays`（例如`1,2,3,4,5`，0是周日）、`workStartTime`、`workEndTime`和`sections`（`login`、`session`、`command`、`file`、`approval`、`account`、`asset`）；或者用`id`指定一份定时报表。
- `GET /api/download-report`参数相同，另加`lang`（`en`或`zh`），返回Excel文件。
- `get-reports`、`get-report`、`add-report`、`update-report`、`delete-report`和`run-report`管理定时报表。
