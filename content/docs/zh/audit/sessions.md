---
title: "会话"
description: "通过Casvisor的每一次连接都是一个会话：谁打开的、连哪个资产、用什么协议、从哪个地址和浏览器、连了多久。管理员能看到在线和历史会话，并能停止在线会话。"
---

每一次连接，也就是工作台里的每个标签页、每个资产页面，或者经由[SSH网关](../assets/ssh-gateway.md)的每个连接，都是一个**会话**。管理员在**会话**页面查看，分两个标签：

- **在线**：此刻正开着的连接。
- **历史**：已经结束的连接。

## 记录了什么

| 列 | 含义 |
| --- | --- |
| 资产 | 连接的资产 |
| 协议 | SSH、RDP、VNC或Telnet |
| 用户 | 打开会话的Casdoor用户 |
| 客户端IP | 用户连接时的地址，能查到时附带归属地 |
| 用户代理 | 用户的浏览器和操作系统；经由SSH网关的是客户端的SSH版本，例如`SSH-2.0-OpenSSH_9.6` |
| 连接开始时间 | 连接建立的时间 |
| 命令记录 | SSH会话里执行过的命令数，点进去是[命令记录](./commands.md)页面 |
| 连接持续时间 | 已经连了多久，或者一共连了多久 |

用户关掉标签页或SSH客户端、远端结束连接、网络断开、管理员停止它，或者用户失去了权限时，会话从在线移到历史。

## 实时旁观

在线的SSH会话有一个**旁观**操作，会在新的浏览器标签页里打开这个会话。管理员看到的和用户自己看到的终端一样：先是到目前为止的输出（最多最近512 KB），用来重画屏幕，然后实时显示后面的一切，包括终端大小的变化。旁观是只读的，在这里输入的内容不会到会话里。同一个会话可以有多个管理员同时旁观。

旁观支持网页终端和经由SSH网关的交互式shell。RDP、VNC和Telnet不支持，经由网关只执行命令、传文件或做端口转发的连接也不支持。被旁观的用户不会收到提示。管理员每打开一次旁观，[操作日志](./operation-logs.md#ssh和文件事件)里就记一条`session-monitor`。

## 停止会话

在线会话上的**停止**会立刻断开连接，不论什么协议。用户的标签页会显示连接已关闭；经由网关的SSH客户端会被断开。停止会话并不能阻止他再连上来；要阻止，先改他的[权限](../access-control/permissions.md)。

## 权限收回即断开

用户一旦不再有权连接这个资产，Casvisor会自己结束他的会话：

- 管理员修改或删除一条权限、修改或删除一个资产之后，立刻把所有在线会话重新检查一遍；
- 每30秒把所有在线会话检查一遍，权限过了**结束时间**的会话就在这时结束。

按用户此刻的地址，已经没有任何权限覆盖的会话会被关闭，代码为802，原因例如*The permission to connect to the asset: web-01 has been revoked*或*The asset: my-org/web-01 has been deleted*。SSH网页终端会把原因显示给用户；其他标签页和SSH客户端直接断开。管理员不受影响，因为他们不需要权限。

对经由SSH网关的连接，这项检查还会更新动作：收回上传、下载或端口转发后，下一次传文件或转发连接就会被拒绝，会话本身不断开。

在Casdoor里做的改动（例如把人移出用户组）本身不会触发这项检查，见[Casdoor里的改动什么时候生效](../access-control/users-and-admins.md#casdoor里的改动什么时候生效)。

## 还没做的

会话录像和回放在[路线图](../more/roadmap.md)上。目前Casvisor记得谁在什么时间连了哪台服务器、SSH会话里执行了哪些命令、传过哪些文件，但没有屏幕录像可以回放。
