title: "会话"
description: "通过Casvisor的每一次连接都是一个会话：谁打开的、连哪个资产、用什么协议、从哪个地址和浏览器、连了多久。管理员能看到在线和历史会话，旁观和回放它们，并能停止在线会话。"
---

每一次连接，也就是工作台里的每个标签页、每个资产页面，或者经由[SSH网关](../assets/ssh-gateway.md)的每个连接，都是一个**会话**。管理员在**会话**页面查看，分两个标签：

- **在线**：此刻正开着的连接。
- **历史**：已经结束的连接。

## 记录了什么

| 列 | 含义 |
| --- | --- |
| 资产 | 连接的资产 |
| 协议 | SSH、RDP、VNC、Telnet、MySQL、PostgreSQL、SQLServer、Oracle、Redis或MongoDB |
| 用户 | 打开会话的用户 |
| 账号 | 会话所用的[系统账号](../assets/accounts.md)；用资产自己的账号时显示*默认* |
| 客户端IP | 用户连接时的地址，能查到时附带归属地 |
| 用户代理 | 用户的浏览器和操作系统；经由SSH网关的是客户端的SSH版本，例如`SSH-2.0-OpenSSH_9.6` |
| 连接开始时间 | 连接建立的时间 |
| 命令记录 | SSH、Telnet和数据库会话里执行过的命令或数据库语句数，点进去是[命令记录](./commands.md)页面 |
| 连接持续时间 | 已经连了多久，或者一共连了多久 |

用户关掉标签页或SSH客户端、远端结束连接、网络断开、管理员停止它，或者用户失去了权限时，会话从在线移到历史。

每个会话有这些操作：

| 操作 | 标签页 | |
| --- | --- | --- |
| 旁观 | 在线 | 实时旁观，见下文 |
| 回放 | 在线和历史，有录像时 | 在新标签页里播放[录像](./recordings.md) |
| 停止 | 在线 | 断开连接，见下文 |
| 删除 | 历史 | 从列表里删掉，连同它的录像 |

列表可以用**导出**下载成CSV或Excel文件，见[导出与syslog转发](./export.md)。

除了用户打开的连接，[作业](../assets/jobs.md)在每台资产上的执行也是一个会话，模式为`job`，用户代理为`Casvisor job`。作业在这台资产上跑完，会话就结束；停止它，就停止这台资产上的作业。

## 实时旁观

在线会话有一个**旁观**操作，会在新的浏览器标签页里打开这个会话，只读：在这里输入或点击的内容不会到会话里。同一个会话可以有多个管理员同时旁观。

- **SSH和Telnet**：管理员看到的和用户自己看到的终端一样：先是到目前为止的输出（最多最近512 KB），用来重画屏幕，然后实时显示后面的一切，包括终端大小的变化。
- **VNC、RDP和[Casvisor浏览器](../assets/websites.md#casvisor浏览器)**：先从会话开头画到当前，再实时跟随。这读的是正在写入的会话录像，所以需要打开录像，见[录像](./recordings.md#录像和实时旁观)。
- **数据库**：没有画面可看，**旁观**打开的是到目前为止执行过的语句列表，带结果，每3秒刷新一次。会话结束后，**回放**显示同样的列表。见[数据库](../assets/databases.md#记录了什么)。

经由SSH网关的交互式shell可以旁观；只执行命令、传文件或做端口转发的连接不行。被旁观的用户不会收到提示。管理员每打开一次旁观，[操作日志](./operation-logs.md#ssh和文件事件)里就记一条`session-monitor`。

## 分享会话

任何用户都可以把自己的会话分享给本组织的同事，比如请人一起看一个问题。在浏览器里打开的SSH、Telnet、VNC或RDP会话右上角有**分享会话**按钮，点开后生成分享：

| 字段 | 含义 |
| --- | --- |
| 谁可以加入 | 分享给哪些用户，留空表示本组织任何人。 |
| 对方可以 | **旁观并操作**：能看到终端，也能接管输入，和管理员接管一样。**只能旁观**：只能看。VNC和RDP会话只能旁观。 |
| 有效期 | 10分钟到8小时。 |

每个分享有一个链接`https://casvisor.example.com/share/<组织>/<编号>`和一个6位验证码，两样都要交给对方，可以用**复制链接和验证码**。对方打开链接、登录、填写验证码后加入。验证码连续错5次，分享自动撤销。

有人在会话里时：

- 会话里会提示谁加入、谁离开，例如*[Casvisor] alice is watching this session through a share*。
- 对方输入的命令按[命令规则](./commands.md)对对方生效，并以对方为操作人记下，命令记录页面能看出是谁输入的。对方自己不需要这台资产的权限。
- 在同一个对话框里撤销分享、分享到期或者会话结束，对方几秒内断开。

生成分享和每次加入都记在[操作日志](./operation-logs.md)里，动作是`session-share`、`session-share-join`和`session-share-control`。

## 停止会话

在线会话上的**停止**会立刻断开连接，不论什么协议。用户的标签页会显示连接已关闭；经由网关的SSH客户端会被断开。停止会话并不能阻止他再连上来；要阻止，先改他的[权限](../access-control/permissions.md)。

## 权限收回即断开

用户一旦不再有权连接这个资产，Casvisor会自己结束他的会话：

- 管理员修改或删除一条权限、一个资产、一个[系统账号](../assets/accounts.md)，或者用自带账号时修改或删除一个用户，或者收回一条[访问申请](../access-control/access-requests.md)之后，立刻把所有在线会话重新检查一遍；
- 每30秒把所有在线会话检查一遍，权限过了**结束时间**的会话就在这时结束。

按用户此刻的地址，已经没有任何权限覆盖的会话会被关闭，代码为802，原因例如*The permission to connect to the asset: web-01 has been revoked*或*The asset: my-org/web-01 has been deleted*。SSH和Telnet终端会把原因显示给用户；其他标签页和SSH客户端直接断开。管理员不受影响，因为他们不需要权限。

对经由SSH网关的连接，这项检查还会更新动作：收回上传、下载或端口转发后，下一次传文件或转发连接就会被拒绝，会话本身不断开。[到其他资产的端口转发](../assets/ssh-gateway.md#端口转发到其他资产)例外：收回端口转发就会把它断开。

用自带账号时，被禁用或删除的用户会被断开，改用户组也立刻生效。在Casdoor里做的改动（例如把人移出用户组）本身不会触发这项检查，见[Casdoor里的改动什么时候生效](../access-control/users-and-admins.md#casdoor里的改动什么时候生效)。
