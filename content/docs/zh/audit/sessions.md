---
title: "会话"
description: "通过Casvisor的每一次连接都是一个会话：谁打开的、连哪个资产、用什么协议、从哪个地址和浏览器、连了多久。管理员能看到在线和历史会话，并能停止在线会话。"
---

每一次连接，也就是工作台里的每个标签页或每个资产页面，都是一个**会话**。管理员在**会话**页面查看，分两个标签：

- **在线**：此刻正开着的连接。
- **历史**：已经结束的连接。

## 记录了什么

| 列 | 含义 |
| --- | --- |
| 资产 | 连接的资产 |
| 协议 | SSH、RDP、VNC或Telnet |
| 用户 | 打开会话的Casdoor用户 |
| 客户端IP | 用户连接时的地址，能查到时附带归属地 |
| 用户代理 | 用户的浏览器和操作系统 |
| 连接开始时间 | 连接建立的时间 |
| 连接持续时间 | 已经连了多久，或者一共连了多久 |

用户关掉标签页、远端结束连接、网络断开，或者管理员停止它时，会话从在线移到历史。

## 停止会话

在线会话上的**停止**会立刻断开连接，不论什么协议。用户的标签页会显示连接已关闭。停止会话并不能阻止他再连上来；要阻止，先改他的[权限](../access-control/permissions.md)，再停止会话。

## 还没做的

实时旁观会话、录像和回放、记录SSH会话里输入的命令，都在[路线图](../more/roadmap.md)上。目前会话列表能告诉你谁在什么时间连了哪台服务器，但看不到他在上面做了什么。
