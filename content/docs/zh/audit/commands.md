Casvisor会记下用户在SSH和Telnet资产上执行的命令，不论是在网页终端里，还是SSH经由[SSH网关](../assets/ssh-gateway.md)和[作业](../assets/jobs.md)，以及用户在[数据库资产](../assets/databases.md)上执行的内容（MySQL、PostgreSQL、SQL Server和Oracle的SQL语句、Redis命令和MongoDB shell调用），并能在你指定的命令执行之前把它拦下，或者先扣住、等管理员批准后再执行。RDP和VNC会话没有命令记录，它们的画面在[录像](./recordings.md)里。

这几个页面都只对管理员开放：**命令记录**（`/commands`）、**命令规则**（`/command-rules`）和**命令复核**（`/command-reviews`）。

## 怎么读出命令

**交互式shell里**，Casvisor在后端维护一块和用户终端一样大的虚拟屏幕，跟着会话走。用户按回车时，它从提示符末尾读到光标，读的是那一刻屏幕上显示的内容。所以记下来的就是实际执行的命令：

- Tab补全、用方向键调出的历史命令、在行中间做的修改，都包含在内。
- 折行的长命令和中文等字符都能读准。
- 打开`vim`、`top`、`less`这类全屏程序时什么都不记。
- shell不回显的输入（例如给`sudo`输入的密码）不在屏幕上，也不会被记下。

**`ssh`命令行上带的命令**，例如`ssh web-01 'systemctl restart nginx'`，按客户端发来的原文记录，也包括`scp -O`和`rsync`在资产上执行的命令。

**作业**的命令或整个脚本，在每台执行它的资产上各记一条；文件分发记为`sftp put <文件> <目标路径>`。

**数据库会话里**，每条语句按发出时的原文记录，一条语句一条记录，一次执行多条时也一样：一条SQL语句、`GO`行之间的一个SQL Server批、一行Redis命令或一条MongoDB shell语句。切换数据库记为对应的语句，例如``USE `db` ``、`\connect db`、`USE [db]`、`SELECT 2`或`use db`，见[数据库](../assets/databases.md#记录了什么)。

## 命令记录页面

每行是一条命令：时间、命令、用户、资产、客户端IP、会话，命中规则时还有规则和它的动作。数据库语句还有一列**结果**，显示返回或影响的行数，或者错误信息。可以按命令、用户、资产、客户端IP和会话搜索，也可以导出成CSV或Excel，见[导出与syslog转发](./export.md)。[会话列表](./sessions.md)里的**命令记录**列是每个SSH、Telnet和数据库会话的命令数，点进去就是这个会话的命令。[录像](./recordings.md)的播放器会在画面旁边列出SSH和Telnet会话的命令，点一条就跳到那里。数据库会话没有录像，它的**回放**就是语句列表。

## 命令规则

一条命令规则写明一个匹配规则，以及命令命中时怎么处理。

| 字段 | 含义 |
| --- | --- |
| 组织、名称 | 规则属于一个组织，作用于这个组织的资产。 |
| 匹配规则 | Go语法（RE2）的正则表达式。命令里任何位置匹配上就算命中，要匹配整条命令请用`^`和`$`。区分大小写，以`(?i)`开头就不区分。数据库会话里按每条SQL语句、SQL Server批、Redis命令或MongoDB调用匹配。 |
| 动作 | `Block`（拦截）、`Review`（复核）或`Alert`（告警）。 |
| 复核人 | 动作为`Review`时，能批准或拒绝这条规则所扣住命令的管理员。留空表示本组织所有管理员。 |
| 用户、用户组 | 对谁生效。两个都不填，或者填`*`，表示所有人。 |
| 资产、资产标签 | 对哪些资产生效。两个都不填，或者填`*`，表示组织里的所有资产。 |
| 启用 | 关掉后这条规则不起作用。 |

规则对管理员同样生效。多条规则同时命中时，拦截优先于复核，复核优先于告警。

几个例子：

| 匹配规则 | 命中 |
| --- | --- |
| `^\s*rm\s+-rf\s+/\s*$` | `rm -rf /`，不命中`rm -rf /tmp/x` |
| `\b(shutdown\|reboot\|halt\|poweroff)\b` | 任何提到这几个词的命令 |
| `^\s*(mkfs\|fdisk\|parted)\b` | 以这几个命令开头的命令 |
| `(?i)^\s*(drop\|truncate\|delete)\b` | 删表、清空表和删除数据的SQL语句，不分大小写 |
| `(?i)^(flushall\|flushdb)\b` | 清空一个或全部数据库的Redis命令 |
| `\.(drop\|dropDatabase)\(` | 删除集合或数据库的MongoDB调用 |

### 拦截

在交互式shell里，Casvisor不把回车传下去，而是发一个Ctrl+C，让这一行不执行就清掉，并在用户终端里显示一行红字：*[Casvisor] The command is blocked by the rule: ...*。对`ssh`命令行上带的命令，网关直接拒绝，提示*casvisor: the command is blocked by the rule: ...*，退出码为1。

在数据库会话里，语句不会发给数据库，控制台显示它被命令规则拦截，同一次执行里排在它后面的语句也不再执行。规则先匹配原样输入的语句，再匹配去掉注释后的语句，SQL Server的批还逐行匹配，Redis去掉引号、MongoDB去掉空格后再匹配，所以在前面加注释或加引号都躲不过去，见[数据库](../assets/databases.md#记录了什么)。在[作业](../assets/jobs.md)里，命令或脚本的每一行都要检查，命中后这台资产上什么都不执行，状态为*已拦截*。

这条命令以动作`Block`记下。

### 复核

命令先不执行，等另一位管理员批准，最多等10分钟。适合那些有时确实要做、但不该一个人说了算的命令，比如重启数据库、删数据。

在交互式shell里，Casvisor扣住回车键，并在用户终端里显示一行黄字：*[Casvisor] The command needs the approval of an administrator by the rule: ..., it waits for review (request ...) for up to 10 minutes, press Ctrl+C to withdraw it*。等待期间敲的键一律丢弃，所以批准的那一行就是执行的那一行。批准后Casvisor把回车键发过去，命令在同一个会话里执行；被拒绝、超时没人复核或用户按Ctrl+C撤回时，这一行像拦截一样被清掉，有复核备注的会一起显示。对`ssh`命令行上的命令，网关把同样的提示打到stderr并等待，断开连接就是撤回。

在数据库会话里，控制台显示这条语句正在等待批准，旁边有**撤回**按钮，批准后执行；被拒绝的语句作为错误返回，同一次执行里后面的语句也不再执行。在[作业](../assets/jobs.md)里，作业在这台资产上等待；作业的超时从命令可以执行时才开始算，取消作业就是撤回。在[网站](../assets/websites.md)上，浏览器没法等，所以这个请求先返回一个“等待复核”的页面；打开的网页每5秒自动刷新一次，批准后就打开，提交的表单则由用户再提交一次。每次批准只放行一次请求，被拒绝的请求10分钟内一直是拒绝。

管理员在**命令复核**页面批准或拒绝，页面列出等待中的命令、用户、资产和会话；还在等待的命令可以先点会话进去实时旁观，再做决定。任何人都不能复核自己的命令，包括自己在别人会话里接管时输入的命令。会话结束时，里面还在等待的命令自动撤回。新的和复核过的命令可以经Webhook（**Webhooks**页面）发到钉钉、飞书、企业微信、Slack或任意地址，事件是`command_review.created`和`command_review.reviewed`，复核人能马上知道。

这条命令以动作`Review`记下，带上复核人，没执行的还会写明原因。

### 告警

命令照常执行，以动作`Alert`和命中的规则记下，可以在命令记录页面里找到。Casvisor不会为它另外发通知；开了[syslog转发](./export.md#转发到syslog)时，它会以Notice级别发到syslog服务器，被拦截的命令则是Warning。

## 规则拦不住什么

规则看到的是输入的那一行命令，有办法绕过：把命令写进脚本再执行脚本，用变量或别名拼出命令，在全屏程序里执行，或者用规则没想到的命令。请把拦截当作防误操作的手段，权限本身仍然要尽量收窄。

规则也只看得到命令。文件和剪贴板走的是各自的通道：文件面板、SFTP、`scp`和`rsync`，RDP的重定向磁盘和剪贴板，VNC的剪贴板。这些由[权限](../access-control/permissions.md)里的**上传**、**下载**、**复制**、**粘贴**动作管，Casvisor在每条通道上都会检查。`ssh`命令行上的命令和不带终端的shell也能把文件管道进出，所以网关只在同时有上传和下载时才放行。要防止数据从资产上带出去，就不要给下载和复制；屏幕上显示的内容用户仍然看得到，[录像](./recordings.md)会把它留下来。
