description: "Casvisor为对它的接口调用记操作日志：谁、从哪里、对哪个对象做了什么，成功没有。默认只记改动类的调用。"
---

操作日志在**日志**页面，回答的是这样的问题：谁加了这个资产，谁放宽了那条权限，谁停掉了某个会话。对Casvisor接口的每一次调用都可能被记下，不论来自界面还是脚本；会话里做的一些事，例如经SFTP传文件，也会记下。

## 每条记录包含

| 字段 | 含义 |
| --- | --- |
| 创建时间 | 调用发生的时间 |
| 组织、用户 | 谁调用的 |
| 客户端IP、用户代理 | 从哪里、用什么调用的 |
| 方法、请求URI | HTTP调用，例如`POST /api/update-permission` |
| 操作 | 接口动作，例如`update-permission`或`stop-session` |
| 对象 | 请求体：发送的资产、权限或会话 |
| 响应 | 是否成功，失败时的错误 |

请求体里的密码和私钥在记录前会被替换成`***`。

## 记哪些调用

默认`logPostOnly = true`，只记`POST`调用，也就是会改动东西的那些：添加、修改、删除资产和权限，开始和停止会话，登录和退出。改成`false`会把读取类调用也记下来，日志会大很多。对日志本身的操作从来不记。

## SSH和文件事件

有些事发生在会话里，而不是通过接口调用，Casvisor会自己为它们写一条记录。这些记录的**方法**是`SSH`或`SFTP`，**请求URI**里是详情（例如路径），**对象**是资产。

| 操作 | 什么时候 | 详情 |
| --- | --- | --- |
| `ssh-connect` | 经由[SSH网关](../assets/ssh-gateway.md)的连接登录上资产 | |
| `ssh-forward` | 网关连接第一次转发到某个目标 | `主机:端口`，或socket路径 |
| `sftp-download` | 经SFTP打开文件读取，或在[文件面板](../assets/file-transfer.md)里下载 | 路径 |
| `sftp-upload` | 经SFTP打开文件写入，或在文件面板里上传 | 路径 |
| `sftp-mkdir`、`sftp-rmdir`、`sftp-remove` | 经SFTP新建或删除文件夹，或删除文件 | 路径 |
| `sftp-rename` | 经SFTP重命名文件或文件夹 | `旧 -> 新` |
| `sftp-symlink`、`sftp-link` | 经SFTP建链接 | `链接 -> 目标` |
| `session-monitor` | 管理员打开某个会话的[实时旁观](./sessions.md#实时旁观) | 会话 |

这些记录不受`logPostOnly`影响，总会写入。SSH会话里执行的命令不在这里，在[命令记录](./commands.md)页面。

## 保留期限

记录会一直保留，直到你删除它。目前没有保留期限的设置；`record`表太大时，直接在数据库里清理。
