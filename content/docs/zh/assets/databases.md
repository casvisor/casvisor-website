MySQL和PostgreSQL服务器也可以作为资产。用户在浏览器标签页的SQL控制台里打开它们，数据库账号由服务端填入；用户执行的每条语句都经过Casvisor：先按[命令规则](../audit/commands.md)检查，再连同结果一起记录，并按会话列出。

## 添加数据库

照常添加资产（见[资产](./assets.md)），其中：

| 字段 | 取值 |
| --- | --- |
| 协议 | `MySQL`（也适用于MariaDB）或`PostgreSQL`。端口会填成3306或5432。 |
| 主机、端口 | 数据库服务器，从Casvisor或资产的[网域网关](./network-gateways.md)能连到的地址。 |
| 用户名、密码 | 数据库账号。和其他资产一样，可以不填，让每个用户连接时自己输入。 |
| 数据库名 | 连接后默认打开的数据库，可以不填：MySQL这时不选中任何数据库，PostgreSQL和`psql`一样打开与用户同名的数据库。 |

数据库资产同样可以有[系统账号](./accounts.md)，例如同一台服务器上的`readonly`和`admin`，由权限决定谁用哪个。它们的密码Casvisor改不了，Casvisor只经SSH改密。

Casvisor用Go的MySQL驱动和pgx连接；服务器支持TLS时就用TLS，但不校验服务器证书，否则用明文连接。资产配置了网域网关时，每个连接都经由网域网关。

## SQL控制台

连接后，在工作台的标签页或资产单独的页面里打开控制台：

- **左侧**列出数据库、当前数据库的表（PostgreSQL会带上schema）以及某张表的列，并标出主键。**切换到这个数据库**把它设为当前数据库，**查询这张表**会在编辑器里填入`SELECT * FROM <表> LIMIT 100;`。
- **编辑器**用**执行**或Ctrl+Enter执行选中的部分，没选中就执行全部。用`;`隔开的多条语句依次执行，每条有自己的结果。拆分语句时会识别字符串、带引号的名称和注释，其中的`;`不会把语句拆开。一批语句遇到第一条失败或被拦截的就停下。
- **结果**显示语句返回的行，或者影响了多少行，以及耗时。每个结果只保留前1000行，单元格超过64 KB会截断，二进制值以十六进制显示，整个结果到8 MB就不再增加。

语句在同一个连接里逐条执行，所以`SET`、事务和临时表在整个会话里都有效；PostgreSQL切换数据库时会新建一个连接。关闭标签页或管理员停止会话会切断连接，正在执行的语句也随之结束。

### 复制和导出

用户的权限有**复制**时，结果旁有一个按钮，把结果复制成制表符分隔的文本，可以直接粘贴进表格。有**下载**时，**导出 CSV**把结果存成Excel能按UTF-8打开的CSV文件。导出在服务端检查，能导出当前会话里最近20个有返回行的结果。每次导出都会以`sql-export`记进[操作日志](../audit/operation-logs.md)，带上语句。

其他动作（粘贴、上传、端口转发）在控制台里不起作用；能不能打开控制台由连接动作决定。

## 记录了什么

每条语句都是会话的一条[命令记录](../audit/commands.md)，带时间、用户、资产、客户端IP、协议和结果：行数或错误信息。切换数据库会记成对应的语句，MySQL是``USE `db` ``，PostgreSQL是`\connect db`。会话列表的**命令记录**一列统计这些语句。

命令规则在语句发出之前逐条检查：

- **拦截**：语句不发给数据库。控制台显示*被命令规则拦截*和规则名，记录的动作是`Block`。
- **告警**：语句照常执行，记录带上规则和动作`Alert`。

规则先匹配原样输入的语句，再匹配去掉注释后的语句，所以`/* note */ DROP TABLE t`照样会被`^\s*DROP`拦住。MySQL的`/*! ... */`注释里的内容服务器是会执行的，这部分保留。模式区分大小写，写SQL规则时以`(?i)`开头：动作为拦截的`(?i)^\s*(drop|truncate|delete)\b`能挡住删表、清空表和删除数据。

数据库会话没有画面可[录像](../audit/recordings.md)。在[会话列表](../audit/sessions.md)里，在线数据库会话的**旁观**打开它的语句列表，每3秒刷新一次；已结束的会话，**回放**显示同样的列表（前1000条），每条有时间、结果和命中的规则。

## 本地客户端

SQL控制台是受审计的入口。用户自己电脑上的数据库客户端，例如`mysql`、`psql`或DBeaver，可以经[SSH网关的端口转发](./ssh-gateway.md#端口转发到其他资产)连数据库资产，例如`ssh -p 2222 -N -L 13306:db-01:3306 alice@casvisor.example.com`。这种连接Casvisor原样转发、不解析：用户用自己知道的账号登录，语句既不记录也不按规则检查。它需要**端口转发**动作，所以只给该有的人。
