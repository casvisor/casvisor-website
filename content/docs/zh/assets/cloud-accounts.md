不用一台台添加云服务器，添加它们所在的云账号就行。Casvisor通过云厂商的API列出账号里的服务器，给每台服务器保留一个资产：新服务器建成新资产，资产的地址、显示名和系统跟着服务器走。这个页面只对管理员开放：**云账号**（`/cloud-accounts`）。

Casvisor只读取服务器列表，所以只读的密钥就够了：

| 云厂商 | 凭据 | 够用的权限 |
| --- | --- | --- |
| 阿里云 | RAM用户的AccessKey ID和Secret | `AliyunECSReadOnlyAccess` |
| AWS | IAM用户的Access key ID和Secret access key | `AmazonEC2ReadOnlyAccess` |
| 腾讯云 | CAM用户的SecretId和SecretKey | `QcloudCVMReadOnlyAccess` |
| Azure | 租户ID、订阅ID，以及服务主体的客户端ID和客户端密码 | 订阅上的“读者”角色 |
| Google Cloud | 服务账号的JSON密钥；项目默认是密钥所在的项目 | 项目上的Compute Viewer角色 |

密钥和资产的口令一样加密保存，页面上显示为`***`。

## 字段

| 字段 | 含义 |
| --- | --- |
| 云厂商 | 阿里云、AWS、腾讯云、Azure或Google Cloud。 |
| 凭据 | 见上表。 |
| 地域 | 只同步这些地域的服务器，留空表示所有地域。**读取地域**会列出账号可用的地域，也能检查凭据是否可用。 |
| 连接地址 | 用服务器的公网IP连接、没有时用内网IP，或者反过来先用内网IP。Casvisor或下面的网域网关和服务器在同一个网络里时选内网IP。 |
| Linux用户名、Windows用户名 | 新资产连接时用的用户。Linux服务器建成22端口的SSH资产，Windows服务器建成3389端口的RDP资产。 |
| 资产树节点 | 新资产放到资产树的这个节点下，每个地域一个子节点，没有时自动建，例如`云/阿里云/cn-beijing`。留空则新资产不放进任何节点。 |
| 标签、网域网关 | 新资产的标签和网域网关。[网域网关](./network-gateways.md)用来连接内网里的服务器。 |
| 同步间隔 | 单位分钟，至少5。填`0`只在点**同步**时同步。 |
| 删除已不存在的服务器 | 服务器已不在云账号里时删除对应资产。关闭时只标为缺失。 |
| 启用 | 关闭后不再定时同步。 |

## 同步

在列表或编辑页点**同步**，先显示预览：每台服务器的资产是新建、更新还是不变，失败的行写明原因。点**立即同步**才真正执行。定时同步直接执行，列表里显示每个账号上次同步的时间和结果。

同步会做的事：

- **新服务器**建成一个以服务器名命名的资产。名字被别的资产占用时，在后面加上服务器ID的末尾，例如`web-01-3f9c2a1b`。新资产没有口令和密钥，之后在资产或它的[系统账号](./accounts.md)里设置。
- **已同步的资产**更新为服务器的显示名、地址、系统和描述。你在资产上改的其他内容都保留，比如协议、端口、用户名、节点和权限。资产页面上会显示它同步自哪个云账号、哪台服务器。
- **地址变了**时，如果资产保存了口令或私钥，不会改地址：保存的口令和私钥只用于保存时的地址，这样云账号里的改动没法把它们带到别的主机上。这一行会失败并说明原因，重新填写口令或者清空后再同步即可。
- **服务器已不存在**时，对应资产标为缺失；开了**删除已不存在的服务器**时删除。云账号一台服务器都列不出来时，什么都不删。

云账号改名后，它的资产照常同步。删除云账号时资产保留，但不再同步。
